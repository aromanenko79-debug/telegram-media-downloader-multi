# Telegram Media Downloader MULTI

Загрузчик фотографий и видео из доступных вашему аккаунту Telegram-чатов для Windows.

## Возможности

- До 6 одновременных загрузок, рекомендуется начать с 3
- Вход по QR-коду через Telegram, без SMS
- Живая панель прогресса, проценты по файлам и скорость
- Автоматические единицы размера: КБ, МБ, ГБ, ТБ
- Учёт уже скачанных медиафайлов в SQLite, повторный запуск после остановки
- Дополнительный режим отслеживания новых файлов, пока программа работает
- **English / Русский:** выбор при первом запуске, затем язык сохраняется в `settings.json`

## Куда распаковать программу (Windows)

Это переносимый проект Python: **диск D: и специальная папка установки не нужны**. Скачайте **Code → Download ZIP**, нажмите **«Извлечь всё»** и выберите любую доступную для записи папку, например `C:\Users\ВАШ_ПОЛЬЗОВАТЕЛЬ\Apps\TelegramMediaDownloader\`. Можно использовать другой диск. Не запускайте `.cmd` прямо из ZIP.

Все файлы проекта и подпапка `locales` должны находиться вместе. Запускайте `start_multi_windows.cmd` из распакованной папки. Перемещать приложение в `Program Files` и запускать от администратора не требуется.

**Папка программы и папка фото/видео — разные каталоги.** При запуске пользователь отдельно выбирает папку архива, например `C:\Users\ВАШ_ПОЛЬЗОВАТЕЛЬ\Videos\TelegramArchive`. Программа создаст там `chat_<id>` с каталогами `photos`, `videos` и базой `download_state.sqlite3`. Проверьте свободное место на диске.

Рядом с Python-файлами сохраняются личные `settings.json` и `telegram_account.session`. Не публикуйте их. При обновлении распакуйте новую версию отдельно, перенесите эти два файла в новую папку программы, а существующий медиаархив и его базу SQLite оставьте на месте.

## Установка

1. Установите Python 3.10 или новее.
2. Скачайте проект целиком через **Code → Download ZIP**, распакуйте.
3. Запустите `start_multi_windows.cmd` в распакованной папке.
4. Выберите язык и укажите собственные `API ID` и `API HASH` с <https://my.telegram.org/apps>.
5. В Telegram на телефоне откройте **Настройки → Устройства → Подключить устройство** и отсканируйте QR-код.
6. Выберите чат, папку архива и количество одновременных загрузок.

Не публикуйте `settings.json`, `*.session`, `download_state.sqlite3` и скачанные медиафайлы. При переносе старого архива сохраняйте всю папку `chat_<id>` с базой.

## Ограничения

Общий процент предварительный, пока идёт сканирование истории. Прерванный файл может скачиваться заново. Скорость и ограничения зависят от Telegram и сети.

Это исходный код Python, не готовый исполняемый EXE. Проверка на сторонних системах ещё требуется.
## Ошибка database is locked

Если появилось `sqlite3.OperationalError: database is locked`, закройте все окна загрузчика и убедитесь, что прежний процесс Python завершён. Не запускайте QR и MULTI одновременно из одной папки. В обновлённой версии есть блокировка второго экземпляра (`instance_lock.py`); **этот файл должен лежать рядом со скриптами**. Не удаляйте `.session` и базу медиаархива для устранения ошибки. Сначала остановите старую версию.
